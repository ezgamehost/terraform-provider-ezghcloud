# Terraform Provider for EZGH Cloud

Manage EZGH Cloud infrastructure with Terraform.

This repository is in the design stage. There is no released provider or Terraform
Registry installation available yet.

The proposed first release covers projects, VPCs, subnets, firewalls, SSH keys,
instances, and volumes, with import and lookup data sources.

See the [provider design](docs/superpowers/specs/2026-11-01-terraform-provider-design.md).

## Development

The proposed implementation uses Go and HashiCorp's Terraform Plugin Framework.
Build commands, acceptance test instructions, examples, and generated reference
documentation will be added with the implementation.
